# HyperL Optional JVM Workbench Client

> **Notice:** The JVM workbench is an optional client visualization tool. 
> The core HyperL engine is written in native C/C++ with a stable C ABI (`native/include/hyperl_engine.h`) and first-class Python SDK (`python/`).

To build and run the optional JVM client:
```bash
./gradlew run
```
