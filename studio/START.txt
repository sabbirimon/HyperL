HyperL Studio
Extract the complete archive into one directory. Launch HyperL-Studio.exe on
Windows or ./HyperL-Studio on macOS and Linux. Choose Local generation for
offline CPU inference with the bundled GGUF starter. Run the launcher with
--local-check to perform a short generation check. The native command-line
engine is alongside Studio. Source-only builds require Python with Tk.

Choose a local immutable SafeTensors file, enter its trusted SHA-256 and the
activation and weight tensor names. Keep the file unchanged during execution.
CPU plan previews report the native allocation budget. For GPU projection,
find processors and select an adapter. Write each result to a new file.
